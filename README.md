# CarbonMind AI

تطبيق Windows مستقل لمساعد المستندات.

- React + Tauri + SQLite
- استيراد PDF وDOCX وTXT
- فهرسة محلية للمستندات
- إجابات مقيدة بمستندات العميل
- OpenAI Responses API عند حفظ المفتاح
- ترخيص مرتبط ببصمة الجهاز
- مثبت NSIS مستقل

## Build

```powershell
npm install
.\scripts\build-windows.ps1
```
